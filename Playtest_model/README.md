# Local playtest data

This directory defines the expected local test-data layout. Raw acquisition data
and generated analytical outputs are intentionally excluded from Git because of
their size.

Tracked structure:

```text
Playtest_model/
├── Testmodel_1_quadrant/
│   └── README.md
└── Testmodel_4_quadrant/
    └── README.md
```

Populate these directories locally according to their README files before running
integration workflows.
